Turning Alaska Site Plan

Site Name

Name: Turning Alaska

Domain: turningalaska.com (Note that the domain is not currently hosting a webpage).

Turning Alaska is a business that my father owns. He is a wood turner and has asked me to make a website for him a few times. I think that this final project would provide a good opportunity to get started on that.

Purpose

The website should serve as a landing page and gallery for my dad and his work. It will have a home page, a gallery with tags (to allow for things like filtering by item type), and it will have a form that will allow a user to sign up for a newsletter.

Scenarios

  • What is Turning Alaska?
  • What are some of the things that Turning Alaska has made?
  • Does Turning Alaska sell wood turnings?
  • How do I purchase wood turnings?
  • How do I contact the owner of Turning Alaska?

Color Schema

The color palatte was selected from here.

  • Background Color: #FEF9F2

    The primary background color of the webpages.

  • Accent 1: #789DBC

    A darker accent. Will mostly be used for borders.

  • Accent 2: #FFE3E3

    Light accent. Used to help highlight some elements

  • Accent 3: #C9E9D2

    Used for headings and footers

  • Accent 4: #FFFFFF

    White, used for greater emphasis and to stand out against the primary background color.

Typography

The only font that will be used is Poppins.
